# Frontend do Catálogo de Filmes

Este frontend consome a API REST do backend para exibir, cadastrar, editar e excluir filmes.

## Tecnologias

- React
- Vite
- Tailwind CSS
- Axios
- React Router

## Como executar

1. Entre na pasta do frontend:
   ```bash
   cd frontend
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o projeto:
   ```bash
   npm run dev
   ```

4. Acesse a aplicação em:
   ```text
   http://localhost:5173
   ```

## Observações

- O frontend faz requisições para a API em http://localhost:3000.
- Certifique-se de que o backend esteja rodando antes de usar a interface.
